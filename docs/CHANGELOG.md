# 更新记录

## v1.0（内部版本码 11）

面向中转站的网站签到与积分/额度领取应用。显示版本为 1.0，当前内部版本码 11；新增设置页底部 GitHub 仓库入口，沿用原签名证书。

我的仓库：<https://github.com/HRylink/daily-checkin-android>。我已经在手机上安装并连接多个网站，签到领取成功；我尚未对所有网站做兼容性验证。

- 动态网站账号卡片：名字、余额/最近领取结果、启用开关、编辑与删除；删除后卡片消失。
- 粘贴网址自动匹配已适配平台；未匹配时提供「添加该网站」通用配置入口。
- 配置网站的 HTTPS 领取接口，完成登录/验证后可参与首页一键签到。
- 简洁首页、圆形签到按钮、领取记录、通知设置和橙色「签」图标。
- 只读余额查询 30 秒节流；自定义接口不用于静默余额查询。
- 认证字段加密、POST 防重放、网络故障隔离；无每日后台定时签到。
- 手机端源码、12 套本地测试和完整说明公开包；不包含电脑端程序、签名私钥、内部参考或验证日志。

## 历史功能演进

- **1.9 / code 10**：移除首页站点提示行；未知网址可进入「添加该网站」。
- **1.8 / code 9**：全部账号动态卡片化，网址输入自动识别；新增五档启动器图标。
- **1.7 / code 8**：重构账号管理页，提供配置编辑、通知和记录入口。
- **1.6 / code 7**：增加余额/积分展示、只读查询与缓存。
- **1.5 / code 6**：新增通用网站配置、Cookie 登录、HTTPS 限制及 POST 当天不重放。
- **1.4 / code 5**：网站账号框架、网址识别、独立开关和登录验证。

网址识别仅匹配已适配域名，不会自动发现任意中转站的签到 API。通用网站仍需填写实际领取接口；只有用户点击后才执行每日任务。
