# 每日签到 v1.0

Android 8.0 及以上的独立签到应用，面向可领取积分/额度的中转站。包名 `com.velpro.checkin`，显示版本 `1.0`，内部 `versionCode=11`。

## 下载与安装

下载本 Release 的 `签到.apk`，允许浏览器/文件管理器安装未知来源应用后安装。`SHA256SUMS.txt` 提供安装包 SHA-256。

既有同签名安装请直接覆盖，不要先卸载，以免丢失账号和记录。自行编译的 APK 使用另一签名，不能保证覆盖本 Release。

## 功能

- 多网站账号卡片、启用开关、删除和重新登录。
- 粘贴中转站网址自动识别已适配平台；其他网站可进入「添加该网站」，自行填写 HTTPS 领取接口并登录验证。
- 首页点击启动一键签到，前台服务继续执行并记录结果；**没有每日自动定时任务**。
- 已适配账号支持时显示只读余额/积分，查询节流；自定义领取接口不会被用作余额查询。
- 认证数据加密保存；无广告和分析上报代码。
- 白底橙色「签」字图标；设置页底部可打开 GitHub 仓库。

## 使用边界

未知网站不能仅凭首页网址推导可靠的签到接口。自定义站点需要填写领取 URL、请求方法及必要配置；仅适用于 Cookie 登录即可调用的接口。自定义登录验证会立即调用一次领取接口，HTTP 2xx 不保证积分/额度到账，请查看站点原文。

POST 请求不会自动网络重放；未确认时当天不再自动重试。删除后重新添加不应被用于绕过保护，应先在站点核对领取结果。

## 验证

手机端 12 个本地测试套件通过，APK 对齐及 v2/v3 签名校验通过。我已经在手机安装，并连接多个网站成功完成签到领取。但我还没有验证所有网站、所有机型和全部生命周期，自动测试与我测试成功的几个网站不代表全面兼容。
