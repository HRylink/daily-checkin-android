# 隐私与数据说明

「每日签到」用于在手机上添加网站并执行积分/额度领取任务，适合支持此类接口的中转站。APK 不内置真实账号、密码、API Key 或个人 Cookie，也没有开发者运营的数据收集服务器。

## 本地存储

- 网站与账号清单、开关、接口配置、余额缓存、POST 当天防重发标记及领取历史保存在应用私有 SharedPreferences/files 中。通常其他应用不能直接读取，卸载或清除应用数据会删除它们；应用禁止备份。
- **用户名、显示名称、网站配置和领取历史不加密。**不要在名称、网址、请求体或额外请求头中写密码、Cookie、Authorization、Bearer 令牌或 API Key。自由文本无法被自动判断为安全，网站返回的原文也可能包含账号信息。
- 密码、会话 Cookie、访问/刷新令牌、敏感账号标识和设备密钥等认证字段按存储键规则使用 AndroidKeyStore AES-GCM 加密，密钥不可导出，密文格式为 `gcm:<iv>:<ct>`。
- WebView 登录态由本机 WebView 的 Cookie 存储管理，不应理解为所有 WebView 存储都采用上述应用层加密。自定义领取所用 Cookie 会另行加密保存到应用配置中。

## 网络通信

- 应用仅发起用户显式触发的登录、签到/领取和验证，以及设置页可见时的只读余额查询。没有开发者分析、遥测、广告或崩溃上报代码。
- 请求会发往用户所添加的网站、对应的登录授权服务、接口地址及 WebView 页面所加载的资源。应用不把这些数据转发给开发者，不提供内置代理；网络使用手机当前系统网络、代理或 VPN。
- 部分已适配账号支持只读余额/积分查询，每站点至少间隔 30 秒；失败保留旧值。自定义领取接口不会被当作余额接口调用。
- 自定义接口只接受 HTTPS，接口重定向仅跟随同源 HTTPS。网页登录可通过 HTTPS 跨站授权；领取 Cookie 始终只读取领取接口作用域。
- 证书错误会取消加载；自定义额外头不能覆盖 Cookie、Authorization、Host、Content-Length 等字段。
- 自定义登录验证会显式调用一次领取接口，可能产生实际领取行为。HTTP 2xx 不等于积分或额度已到账。

## 删除与升级

- 删除账号会清除对应本机凭据、缓存和自定义配置，不会注销远端网站账号。
- **某些使用第三方授权的内置账号在删除时会调用 `CookieManager.removeAllCookies()`，清空本应用 WebView 的全部 Cookie。**这可能使其他网页账号也需要重新登录；其他账号删除不会统一清空 WebView Cookie。
- 同包名、同签名的覆盖安装可保留本机数据。自行编译的不同签名包不能直接覆盖官方包；卸载会删除数据。

## 权限与任务

只使用联网、前台数据同步服务和通知权限，不申请短信、联系人、位置或外部存储权限。没有后台每日定时任务或开机签到；前台服务在点击按钮后继续执行，通知仅在手机本地显示。
